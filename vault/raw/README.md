# raw/ — Fuentes crudas

Aquí van los documentos de origen. **Son inmutables:** el LLM los lee pero nunca los edita.

Ejemplos de lo que va aquí:

- Requisitos o ideas de funcionalidades
- Notas de reuniones y conversaciones con clientas o usuarias
- Feedback, capturas de bugs, grabaciones transcritas
- Specs o capturas de diseño (Figma exportado, bocetos)
- Artículos o documentación externa relevante (Expo, Supabase…)

Convenciones:

- Nombre: `YYYY-MM-DD-slug.ext` (fecha en que entra al vault).
- Imágenes y adjuntos: `raw/assets/` (Obsidian está configurado para guardarlos ahí).
- Después de añadir una fuente, pide a Claude: *"ingesta `raw/<archivo>`"*.
